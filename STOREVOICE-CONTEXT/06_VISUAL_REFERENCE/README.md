---

## Rules for Visual References

1. **An image alone is never a design decision.** A visual reference becomes authoritative only after the human owner approves the resulting specification.

2. **Lifecycle tracking.** All visual references must be tracked through the lifecycle above.

3. **Approval required.** Visual references become approved only after human owner approval.

4. **Documentation required.** Each visual reference should include:
   - Description of what it represents
   - Why it was considered
   - Current status in the lifecycle
   - Any associated decisions

5. **Rejection tracking.** Rejected references should include the reason for rejection.

---

## How to Add Visual References

1. Place the image in the appropriate directory based on its status
2. Create a corresponding markdown file with metadata
3. Update this README if adding new categories
4. Record the addition in `05_DECISIONS/CHANGELOG.md`

---

## Rules for Future Updates

- Visual reference changes require human owner approval
- All modifications must be recorded in `05_DECISIONS/CHANGELOG.md`
- Changes must follow the governance workflow in `AGENTS.md`
- Visual updates may require corresponding updates to `02_DESIGN/VISUAL_DIRECTION.md`
